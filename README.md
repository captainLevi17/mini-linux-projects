# CompTIA Linux+ Hands-On Projects

Welcome to my repository for practical Linux system administration projects! This repository tracks my progress as I study for the **CompTIA Linux+** certification through weekly hands-on mini-projects.

Each project is designed to build practical shell scripting skills, master core Linux utilities, and solidify key concepts required for real-world system administration and the Linux+ exam.

---

## 🛠 System Environment
- **OS / Distribution:** Linux Mint 22.3
- **Kernel:** `7.0.0-38-generic`
- **Shell:** Bash (`/bin/bash`)
